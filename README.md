| 内容 | 体验 |
| --- | --- |
| 动态历史总览 | 四路红军事件时间轴、地图与事件渐进展开 |
| 七幕历史叙事 | 于都、湘江、遵义、赤水、泸定、雪山草地、抵达与会师 |

## 历史与艺术声明

作品采用 Natural Earth 现代陆地轮廓和近似地理事件定位，地图动态连线用于表达**历史事件先后**，并非经过考证的长征军事行军路线。作品中后世历史主题绘画不等于现场照片；各章提供史料索引，摄影、绘画及地图的来源在结语列出。
